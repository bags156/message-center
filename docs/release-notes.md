Message Center 1.5.33.

- Opening a chat that has a link preview (a YouTube link, say) no longer flickers.
  - The preview used to show up without its picture for a moment. Then the picture popped in and the whole chat jumped. It happened again each time a new message or read receipt redrew the chat.
  - Now the picture's space is there from the start and a picture already loaded goes straight back in, so nothing moves.
  - After restarting the app, previews show as soon as the chat opens instead of a moment later.
