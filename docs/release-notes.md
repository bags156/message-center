Addresses, backgrounds, and cleaner previews.

- **Tap an address to map it.** Street addresses in messages ("805 SE J St, Bentonville, AR 72712", "123 Main Street Apt 4") are underlined; tap one to open it in your maps app. The first time, pick which maps app to use; change it in Settings → Maps app for addresses (or choose "Ask every time"). Shared location pins open in the same app.
- **Chat backgrounds.** Chat menu → Theme & background: pick one of six built-in backgrounds (Dusk, Misty forest, Ocean, Aurora, City lights, Starry night) or one of your own photos. Backgrounds are dimmed slightly so names and times stay readable. Each chat can have its own.
- **No more emoji on media previews:** the chat list and notifications say "Photo", "Video", "Voice message", or the file name, without 📷 and friends.

Install over 0.9.0; the package and signing key are unchanged.
