Incoming messages, a redesigned inbox and chat, pinned chats, chat themes, and per-chat read receipts.

- **Incoming messages fixed.** Message direction now comes from Google's message status. Previously a sender flag could mark incoming messages as yours, so they showed as your own and did not notify you.
- **New look.** The inbox has contact photos (or colored initials), names, previews ("You: …" for your messages), times, unread styling, drafts, and a Start chat button. Search and Archived are in the top bar. Chats have a top bar with photo, name, call button and menu; rounded bubbles that group together; time separators; read/delivered ticks under your latest message; and a rounded message box. Older messages and conversations load as you scroll. Light and dark mode follow your phone.
- **Pinned chats.** Chats pinned in Google Messages show at the top with a pin. Long-press a chat (or use ⋮ in a chat) to pin or unpin it in Message Center. Google's protocol has no pin action, so this does not change Google Messages.
- **Chat themes.** Choose a color theme per chat for your bubbles and the send button.
- **Read receipts per chat.** On by default. When on, opening the chat marks it read on your phone and Google Messages sends a read receipt (if its own "Send read receipts" setting is on). When off, the chat is not marked read, so no receipt is sent and it stays unread in Google Messages. Opening that chat in the Google Messages app itself would still send one.
- Long-press a message to reply, react, remove your reaction, or copy text.

Install over 0.2.x; the package and signing key are unchanged. Attachments are still labels only. Phone testing is still required.
