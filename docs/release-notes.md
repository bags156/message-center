Reactions, replies, typing, group details, better notifications, and chat bubbles.

- **Reactions.** Each message shows one small pill with the emoji used and how many people reacted. Tap it for a clean list of everyone who reacted, with photos, filterable by emoji. Several people and several different emoji on one message are all shown. Long-press a message to react; your current reaction is highlighted, tap it again to remove it, or pick another to change it (Google allows one reaction per person).
- **iPhone reactions sent as text** ("Loved an image", "Liked “…”") now appear as one quiet line instead of a message bubble.
- **Replies, iPhone-style.** A reply shows "↩ Keith replied to you" with the original message as a faded bubble above it and a thread line down to the reply. Tap the original to jump to it. iPhone replies that arrive as "Replied to a message:" are shown the same way. Replying shows the original above the message box with a ✕ to cancel.
- **Read receipts are now off by default** for every chat. Turn them on per chat from its details or by long-pressing it in the list.
- **Typing indicators.** See when someone is typing ("Daniel is typing"). Others see when you type in RCS chats; turn that off in Settings.
- **Group details.** Tap a chat's name (or ⋮ → Group details) to see everyone in it with photos and numbers. Tap a person to message, call, or copy their number. Chat settings (pin, theme, read receipts, bubble) are there too.
- **Notifications** now show who sent each message, the group name, recent messages together, and contact photos. Tapping one opens that conversation.
- **Bubbles.** Chats can float as Android bubbles: tap the bubble button on a message notification, or ⋮ → Open as bubble. Requires bubbles to be allowed in Android's notification settings.
- **Inbox fixes.** Times no longer wrap, the pin icon is redrawn, and chats whose preview Google leaves empty now show the latest synced message.

Install over 0.3.0; the package and signing key are unchanged. Attachments are still labels only. Phone testing is still required.
