Message Center 1.5.73.

- The message box is back to normal: the persistent Translate / Send in control is removed.
- Tap Send once to automatically translate and send using that conversation's Details → Sending language. There is no translation preview or second confirmation. As written sends what you type.
- A short progress line appears only while translation is working. Failed translations keep your draft and explain that the message was not sent.
- Repeated taps cannot start duplicate translations. Changing the draft, reply, attachments, chat or sending language blocks outdated results from sending. Short outgoing greetings use the phone's language as their source; symbols, numbers and links alone are sent unchanged.
- Incoming automatic translation remains app-wide under Settings → Translation.

Update through Obtainium over the existing app. Your pairing, messages, language settings and downloaded language packs are retained.
