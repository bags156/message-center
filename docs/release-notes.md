Message Center 1.5.54.

- Your fonts stay: every font you upload is kept in Settings → Appearance → Font, under the phone's own. Each one is shown in its own lettering. Tap one to use it (a check marks the one in use), or tap its bin to delete it. Uploading the same font again doesn't list it twice. Where it's used (Messages, Titles…) carries over when you switch.
- Demo fonts: free "demo" versions of fonts leave characters out (often digits like 4 and the apostrophe) and draw a "DEMO" mark in their place, which broke times like 7:40. Now those characters use the phone's font instead, and the font's row says which ones ("Demo version: it has no 4 9 '"). Fonts you've already uploaded are checked too. The full version of a font has them all.
- Backups include all your fonts and which one is in use.

Install over the existing app through Obtainium. Your pairing, conversations and settings are retained.
