Verification codes copy themselves.

- **Auto-copy verification codes.** When a new message with a login or verification code arrives, the code goes straight to your clipboard, ready to paste. The notification says "Code … copied", and the Copy button is still there as a backup.
- Only codes from messages arriving now are copied (not older ones loaded from history), each code once, and not from muted chats.
- The code is marked sensitive, so Android hides it in its clipboard preview. Android 13 and later clears the clipboard after about an hour.
- Turn it off in Settings → Auto-copy verification codes.

Install over 0.7.0; the package and signing key are unchanged.
