Better link previews.

- **Amazon and other shops:** sites like Amazon block unknown apps and returned a bot-check page, so previews just said "Amazon.com". The app now asks for previews the way messaging apps do (and still names itself), so sites send the real title and picture. When a page only gives a generic title, the app uses the product name from the link or shows no card instead of a useless one.
- **No more blurry banners:** tiny images (placeholders, logos) were stretched across the whole card. Small pictures now sit beside the title, and only real photos fill the top.
- Previews also show a short description, like Google Messages.
- Old previews are refreshed, so links you already received get fixed too.

Install over 0.8.0; the package and signing key are unchanged.
