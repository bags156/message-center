Message Center 1.5.72.

- Incoming automatic translation now lives in app Settings → Translation. One switch and reading language apply to all chats, with automatic source-language detection.
- Sending language stays in each chat's menu and Details. Choose a different language for each person or group; As written sends what you type. The composer can still override the language for just one message, with a preview before sending.
- Existing reading choices move to the most-used reading language app-wide. Turning incoming translation off remembers the reading language for next time. Sending languages, pairing and downloaded language packs are retained.

Update through Obtainium over the existing app.
