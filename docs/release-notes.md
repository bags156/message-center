Pinned chats up top.

- **Pinned chats are a grid at the top of the list,** three across with big photos and first names, like iPhone Messages. Unread pinned chats get a blue dot; muted or snoozed ones show 🔕 or 💤. Long-press one for its options (including Unpin). The grid hides while you search or in Archived.
- **Slightly smaller chat list rows:** smaller photos and text so more conversations fit on screen. Settings → Text size still scales them.

Install over 0.9.1; the package and signing key are unchanged.
