Message Center 1.5.74.

- Added a stronger offline translator for more natural conversational wording and idioms. Open Settings → Translation → Translation quality and choose Download stronger translator. This is an explicit 4.1 GB Wi-Fi download, checked against a pinned SHA-256 before use. Stronger translation turns on when verification finishes; Compact remains available.
- Chat Details now has I write in as well as Send in. Your writing language follows the phone by default, which prevents long English drafts with slang or names from being mistaken for another language. Automatic detection is still an optional source choice.
- Type normally and tap Send once as before. The stronger engine validates links, codes, times and emoji, keeps drafts on error, and releases the larger model from memory when idle or backgrounded. Receiving translation remains in app Settings.
- Stronger translation uses more storage, memory and processing time. It improves the tested idioms but can still misinterpret ambiguous sentences; comparisons and known limits are in docs/translation-quality.md.

Update through Obtainium over the existing app. Your pairing, messages, chat language choices and previously downloaded compact language packs are retained. Model weights are downloaded only after you choose that in the app.
