Full photos and reply navigation.

- **Fixed "missing download details" on photos.** Some photos arrive with only a preview; your phone keeps the full one until something asks for it. Tapping one now asks your phone for the full photo, shows the preview meanwhile, and swaps in the full photo when it arrives (usually a few seconds). Chats also ask for these automatically, so they show sharp without tapping. The same applies to videos and files that arrive this way.
- Attachments sent inside the message itself now open too.
- **Tap a reply's quote to go to the original message**, even if it is older than what's loaded; older history is loaded until it's found. iPhone replies that don't say which message they answer ("Original message not included") explain that when tapped.

Install over 0.7.1; the package and signing key are unchanged.
